DRY — Don't Repeat Yourself. Спросите: в Банкомате из ДЗ что повторялось? (проверка суммы, вывод баланса) — это кандидаты в функции.

Анатомия функции

function greet(name) {
  return `Привет, ${name}!`;
}

greet('Аня');  // 'Привет, Аня!'
Части подсвечиваются по очереди сами, можно и кликать по легенде. Правило имён: функция что-то ДЕЛАЕТ, поэтому имя — глагол: getTotal, showMenu, isValid. Без скобок greet — это сама функция, со скобками greet() — её вызов.

Параметры и аргументы

Параметр — переменная в объявлении: name, age.

Аргумент — значение при вызове: 'Аня', 20.

Не передали аргумент — параметр равен undefined. Или значению по умолчанию.

  return `Привет, ${name}! Тебе ${age}`;

Меняйте аргументы — JS вызывает функцию по-настоящему. Сотрите второй аргумент — сработает значение по умолчанию 18. Сотрите оба — name станет undefined, и это видно в результате. Аргументы передаются по порядку: первый — в первый параметр.

return

Возвращает результат и сразу выходит из функции. Код после return не выполняется.

Нет return — функция вернёт undefined.

alert показывает, а return — отдаёт значение дальше

Запустите: строка после return не печатается, а shout печатает «Эй!!!», но сама возвращает undefined — поэтому вторая строка в консоли будет undefined. Частая ошибка студентов: alert внутри функции вместо return, а потом результат нельзя использовать.

Рекурсия 🪆

      
Рекурсия — функция вызывает саму себя, каждый раз с задачей поменьше. Как матрёшка.

      
Базовый случай — когда остановиться. Без него — бесконечность.

      
Рекурсивный шаг — свести задачу к меньшей: 5! = 5 · 4!

      
Чтобы понять рекурсию, нужно понять рекурсию 😄

    

    


    

  

  
Запустите. factorial(5) = 5 · 4 · 3 · 2 · 1 = 120. Покажите на доске: factorial(3) → 3 * factorial(2) → 2 * factorial(1) → 1. Следующий слайд показывает это анимацией.

Замыкание 🎒

      
Функция запоминает переменные того места, где её создали, — даже когда внешняя функция уже закончилась.

      
Как рюкзак: функция уносит с собой свои переменные.

      
Каждый вызов createCounter() — новый рюкзак со своим count
