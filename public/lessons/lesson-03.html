Объекты и массивы

Что такое объект · new Object · свойства · Array · методы массива · ссылки и копии · перебор · синтаксис для практики

Цель: каждый может собрать список объектов (корзину, журнал) и пройтись по нему циклом.

Объект {} — анкета 📦

{ ключ: значение }литерал: так пишут почти всегда
new Object()то же самое через конструктор и new
{ title, price }короткая запись: ключ = имя переменной
typeof {} → 'object'объект — отдельный тип данных
Объект — анкета: у каждого значения есть подпись (ключ, он же свойство). new Object() встречается в старом коде и в программе курса — показываем, но пишем литералом. Короткая запись понадобится в практике: cart.push({ name, price, qty }).

Свойства ✏️

user.nameдостать значение через точку
user['age']то же через скобки, ключ — строка
user.city = 'Баку'изменить или добавить свойство
delete user.xудалить свойство
'x' in userесть ли такое свойство? true / false
const не мешает менять содержимое объекта: нельзя только присвоить student = другой объект. Попросите студента предложить своё свойство и добавьте его прямо в коде.

Ключ в переменной 🔑

obj[key]ключ берётся из переменной key
obj.keyищет ключ с именем "key" буквально!
for (const k in obj)пройти по всем ключам объекта
Object.keys · Object.valuesмассив ключей · массив значений
Главная ловушка: prices.what ищет ключ "what" → undefined. Сразу после — квиз именно на это. В практике: promos[code] — скидка по коду из переменной.

Квиз · несуществующий ключ

Несуществующее свойство — не ошибка, а undefined. ReferenceError бывает у несуществующей ПЕРЕМЕННОЙ.

Квиз · точка или скобки

user.key ищет свойство "key" — его нет → undefined. Ключ из переменной — только user[key].

Массив — поезд с вагонами 🚂

индексы — с нуля!

const fruits = ['🍎', '🍌', '🍒'];

Нажимайте кнопки: push и pop работают с хвостом поезда, unshift и shift — с головой, и тогда у ВСЕХ вагонов меняются номера. Обратите внимание: push возвращает новую длину, pop и shift — то, что забрали. Это будет в квизе.

Создание массива

[1, 2, 3]литерал — так пишут почти всегда
new Array(9, 12, 7)объект Array: то же, что [9, 12, 7]
new Array(3)ловушка: 3 ПУСТЫХ места, а не [3]
arr[i] · arr.lengthэлемент по индексу · сколько элементов
Array.isArray(x)это массив? typeof тут не поможет
new Array с ОДНИМ числом создаёт массив такой длины, а не массив из этого числа — классическая ловушка. Запись в индекс за концом создаёт «дыры» — так делать не надо.

Методы: добавить и найти

push(x) · pop()в конец (вернёт новую длину) · забрать последний
unshift(x) · shift()то же самое, но с начала
includes(x)есть ли элемент? true / false
indexOf(x)номер элемента или −1, если нет
arr.at(-1)последний элемент
Первая строка — то, что будет в квизе: push возвращает НОВУЮ ДЛИНУ. indexOf и −1 понадобятся, когда ищем, есть ли элемент.

Копия или та же коробка? 🎁

const b = ab — та же коробка, НЕ копия
[...a]новая копия массива
{ ...obj }новая копия объекта

Числа и строки копируются. Объекты и массивы — передаются ссылкой

Аналогия: const b = a — второй ключ от той же квартиры, а не вторая квартира. Spread из урока 2 делает настоящую копию. Копия понадобится на следующем слайде: sort меняет исходный массив.

Методы: резать и сортировать

slice(from, to)копия кусочка, to не входит; массив цел
splice(i, n)вырезать n штук с индекса i — меняет массив!
join(' + ') · concat(b)массив → строка · склеить два массива
sort() · reverse()sort() сравнивает как СТРОКИ!
sort((a, b) => a - b)числа по возрастанию (b - a — по убыванию)
sort() без функции сравнивает строки: '10' < '2', потому что '1' < '2'. Функция (a, b) => a - b говорит: отрицательное — a раньше. Сортируем копию [...nums], чтобы не испортить оригинал — так будет в практике.

for…of и массив объектов

for (const x of arr)пройти по значениям массива
[{…}, {…}]массив объектов — список анкет
group[0].nameпервый объект → его свойство name
in — ключи · of — значенияне путать!
Массив объектов — самая частая структура в реальных проектах: товары, студенты, сообщения. Корзина в практике — ровно такой массив.

Квиз · что возвращает push

push возвращает НОВУЮ ДЛИНУ — 4. Это было в первой строке примера «Методы: добавить и найти».

Квиз · ссылка на объект

pet и cat — одна коробка → 'Мурзик'. С { ...cat } было бы 'Барсик'.

Квиз · sort без функции

Без функции сравнения sort сравнивает строки: '1' < '10' < '2'. Для чисел — sort((a, b) => a - b).

Синтаксис для практики 1 🛒

cart.push({ name, price, qty })добавить товар-объект в корзину
for (const it of cart)пройти по товарам: it.price * it.qty
lines.join('\n')массив строк → одна строка; \n — перенос
cart.splice(i, 1) · return nullудалить элемент i · «не нашёл»
code in promos · promos[code]есть ли такой ключ · значение по ключу
[...cart].sort((a, b) => b.price - a.price)копия, отсортированная по цене ↓

Строки, Math, Date

Строка как массив букв · методы String · Math и случайные числа · Date · setTimeout и setInterval · синтаксис для практики

Вторая теория — инструменты на каждый день: обработка текста, случайные числа, даты и таймеры.

Строка — буквы в коробках 🔤

неизменяемая!
const s = '';

const s = 'JavaScript';

Строка похожа на массив: у букв есть индексы с нуля, есть length. Но строку нельзя изменить по индексу — s[0] = '!' молча ничего не делает. Методы не меняют строку, а возвращают НОВУЮ. Впишите своё слово в поле.

Методы строк · 1

trim()убрать пробелы по краям
toUpperCase() · toLowerCase()все большие · все маленькие
includes(x) · indexOf(x)есть ли кусок · где он (или −1)
slice(from, to)кусок строки, как у массива
for (const ch of s)пройти по буквам строки
Все методы возвращают новую строку — s не меняется. new String встречается в программе курса: это объект-обёртка, на практике пишем просто кавычки.

Методы строк · 2

split(',') · arr.join(' ')строка → массив · массив → строка
replace(a, b) · replaceAll(a, b)заменить первое · заменить все
repeat(n) · padStart(n, '0')повторить · дополнить до длины
s[0].toUpperCase() + s.slice(1)первая буква большая — частый приём
'\n'перенос строки внутри текста
Приём «первая буква большая» будет в практике: formatName. split и join — мост между строками и массивами.

Квиз · slice

Индексы 0, 1, 2, 3 — правая граница 4 не входит. Как у массивов.

Квиз · неизменяемая строка

Строки неизменяемы: запись по индексу молча игнорируется. Нужна новая строка: s[0].toUpperCase() + s.slice(1).

Math 🧮

Math.PIсвойство: число π
round · floor · ceilокруглить · вниз · вверх
max · min · abs · pow · sqrtбольше · меньше · модуль · степень · корень
Math.random()случайное от 0 (включая) до 1 (не включая)
floor(random() * (max - min + 1)) + minслучайное ЦЕЛОЕ от min до max
Запустите несколько раз — random каждый раз разный. Формулу randomInt разберите по шагам: random() * 6 → от 0 до 5.99…, floor → 0…5, + 1 → 1…6. Она будет в практике.

Date 📅

new Date() · new Date('2026-12-25')сейчас · конкретная дата
getFullYear · getMonth · getDateгод · месяц С НУЛЯ (0 = январь) · число
getDay()день недели: 0 — воскресенье
d2 - d1 · d2 > d1разница в миллисекундах · что позже
d.setDate(d.getDate() + 14)сдвинуть дату на 14 дней
Главные ловушки: месяцы с нуля (getMonth() + 1 для людей) и new Date(2026, 11, 31) — это декабрь. Разность дат — миллисекунды; делим на 1000·60·60·24, чтобы получить дни. setDate сам перелистывает месяц.

Задержки и интервалы ⏱

setTimeout(fn, ms)вызвать fn ОДИН раз через ms миллисекунд
setInterval(fn, ms)вызывать fn каждые ms миллисекунд
const id = setInterval(…)запомнить номер таймера
clearInterval(id)остановить — иначе будет крутиться вечно
1000 мс = 1 секундаи setTimeout не ждёт — код идёт дальше
Запустите и смотрите на порядок: 1, 2, потом через 2 секунды 3, а параллельно отсчёт. Загадка с перерыва: setTimeout(() => back(), 10 * 60 * 1000) — «вернуться через 10 минут».

Квиз · случайное число

random() * 3 → от 0 до 2.99…, floor отрезает дробь → 0, 1 или 2. Чтобы было 1…3, нужно + 1.

Квиз · месяц в Date

Месяцы с нуля: 0 — январь. Людям показываем getMonth() + 1.

Квиз · порядок setTimeout

Даже с задержкой 0 setTimeout выполняется ПОСЛЕ текущего кода: сначала B, потом A. Подробно — в модуле про Promises.

'0123456789'.includes(ch)это цифра? — внутри for (const ch of str)
new Date(birth) · setInterval / clearIntervalвозраст по дате · отсчёт 3… 2… 1…

Программа для школьной библиотеки. Книги хранятся в массиве объектов — минимум 5 книг на старте.

{ title: 'Мастер и Маргарита', author: 'Булгаков',
  year: 1967, pages: 480, isRead: false }
Базовый · 1–6 баллов
  • addBook(books, title, author, year, pages)
  • printBooks(books): «1. Мастер и Маргарита — Булгаков, 1967»
  • countRead(books) — сколько прочитано
Средний · 7–9 баллов
  • findBooks(books, query) — по части названия или автора, без учёта регистра
  • oldestBook(books), averagePages(books) с Math.round
  • markRead(books, title)
Продвинутый · 10–12 баллов
  • borrowBook(book): дата возврата = сегодня + 14 дней
  • isOverdue(book) — просрочена ли
  • «Книга дня» — случайная; напоминание через setTimeout
Весь синтаксис — на слайде «Шпаргалка к ДЗ». Попросите сфотографировать оба слайда.
