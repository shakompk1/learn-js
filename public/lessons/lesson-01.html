Живой калькулятор

Включите «строка» у a и посмотрите на a + b

Калькулятор считает по-настоящему. Включите «строка» у a: a + b превращается в склейку '22', а остальные операторы всё ещё считают как числа. Введите в a буквы — получите NaN. Сравнение и логика

Операторы отношений

Логические операторы

true && false  // false
true || false   // true
!true           // false
0 || 'нет'      // 'нет'
null ?? 'гость' // 'гость'

&& — «и», || — «или», ! — «не», ?? — «значение по умолчанию»

Слева живое сравнение: вводите любые значения — == приводит типы, === сравнивает и тип, и значение. Нажмите пресеты: 0 == '' → true — классический сюрприз. || возвращает первое «истинное» значение, ?? — первое, которое не null и не undefined: 0 ?? 5 → 0, а 0 || 5 → 5.

Кнопка «Как должно работать» запускает пример программы через настоящие prompt и alert — покажите его в начале практики, код при этом не виден. Подсказки: сумма = кофе * чашки + десерт * штуки; с чаевыми = сумма * (1 + чаевые / 100); с каждого = итог / друзья; скидка: итог * (1 - DISCOUNT); сдача = купюра - итог. В конце разберите базовый уровень у доски вместе — один раз для всех.

break и continue

  

    

      
break

      
Немедленно выходит из цикла

      
for (let i = 1; i <= 10; i++) {

  console.log(i);

→ 

    

    

      
continue

      
Пропускает остаток итерации, идёт к следующей

      
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;
  console.log(i);
}

      

      
→ 

    

  

  
Аналогия: break — выйти из автобуса, continue — проехать одну остановку 🚌

  
Запустите оба: в break на четвёрке цикл обрывается, клетки 5–10 так и не проверяются. В continue чётные числа пропускаются, но цикл доходит до конца. Классика break — поиск (нашли — дальше искать незачем); continue — пропуск неподходящих значений.

Практика 2 · Угадай число 🎲

  

    
Компьютер загадывает число, игрок угадывает. Первая строка уже дана — Math.random пройдём позже:

    
const secret = Math.floor(Math.random() * 100) + 1;

  

  

    
Базовый · 1–6 баллов
  • Цикл: спрашивать число, пока не угадано
  • Подсказки «Больше ↑» и «Меньше ↓»
  • В конце — «Угадали! Это было N»

    
Средний · 7–9 баллов
  • Счётчик попыток
  • «Отмена» (null) — выход через break
  • Не число или вне 1–100 — continue, попытка не считается

  • Сложность через switch: 1–50 и 10 попыток, 1–100 и 7, 1–200 и 5
  • Попытки кончились — «Проигрыш, было N»
  • Повтор игры: do…while + confirm
  • Рекорд — лучший результат за все раунды
