Гильдия: онлайн-квизы для урока 5

Локальная проверка:
  npm install
  npm start
  Открыть http://localhost:4175/

При первом входе сайт спрашивает имя. Кружок снизу слева показывает инициалы;
нажатие на кружок показывает полное имя. Имя запоминается в этом браузере.

Преподаватель: кнопка «QR / участники» справа вверху.
Создать сессию, показать QR, перейти к слайду квиза и нажать «Старт».
«Показать ответ» завершает голосование и раскрывает верный вариант студентам.
Доступ преподавателя хранится в sessionStorage текущей вкладки.
Для другой группы завершить сессию и создать новую.
Для разминки: кнопки «Карточка 1» ... «Карточка 6» отправляют вопрос на телефоны.
Переворот активной карточки раскрывает правильный ответ на телефонах.
Во время занятия виден только общий счётчик ответов.
Кнопка «Завершить и показать лидерборд» выводит итоговую таблицу:
место, имя, правильные ответы и число выполненных заданий.
Таблица появляется и у преподавателя, и на телефонах участников.
Каждый вопрос считается один раз. Повторный запуск заменяет прежний результат.

В локальной версии QR с адресом localhost предназначен для проверки на этом
компьютере. Для телефонов нужен опубликованный HTTPS-адрес.

Публикация в Vercel:
  Корневая папка проекта: lesson-live
  Framework: Other
  Output Directory: public
  Build Command: не требуется
  Install Command: npm install
  Node: 22.x или новее

Через Marketplace подключить Redis и передать серверу переменные:
  UPSTASH_REDIS_REST_URL
  UPSTASH_REDIS_REST_TOKEN
Поддерживаются также KV_REST_API_URL и KV_REST_API_TOKEN.
Секреты не помещать в HTML, Git или клиентский код.

В Vercel локальное хранилище намеренно отключено: без Redis комнаты вернут
понятную ошибку. Нельзя хранить общие ответы в памяти serverless-функции.
Все ключи комнаты и ответов имеют срок жизни 6 часов.

Учебная комната, а не экзаменационная система: номер привязан к браузеру.
Вход с другого браузера займёт ещё одно место; предел — 19 участников.
Вопросы и ответы презентации доступны зрителям самой презентации.
Страница join.html получает правильный ответ только после раскрытия.
