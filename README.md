# learn-js

Интерактивный курс JavaScript: пять уроков, 240 слайдов, живые редакторы и практика.

- Главная: выбор главы, урока и конкретной темы; поиск и фильтры.
- /lesson.html?id=01 — просмотр урока с оглавлением.
- /progress.html — прогресс и продолжение с сохранённого слайда.
- /lessons/lesson-01.html … lesson-05.html — самостоятельные презентации.
- В уроке 5: QR-комнаты, ответы с телефонов, 60 секунд на вопрос и итоговый лидерборд.

Имя и прогресс сохраняются в браузере. Между устройствами прогресс не синхронизируется.
Комнаты и ответы хранятся в Redis 6 часов; до 19 участников.

Локально: npm install, затем npm start; открыть http://localhost:4175/.
Параметры Vercel и описание занятия: SETUP.txt.
